# CodeAlpha Internship - Python Projects

This repository contains the Python projects completed as part of the *CodeAlpha Internship Program*.

## ✅ Tasks Completed

### 🟢 Task 1: Hangman Game
A simple text-based Hangman game where the player guesses a hidden word one letter at a time.

- Used a small list of 5 predefined words.
- Maximum 6 incorrect guesses allowed.
- Built using basic Python concepts: random, while, if-else, lists, and strings.

📂 File: hangman.py

---

### 🟢 Task 2: Stock Portfolio Tracker
This script tracks your stock investment using hardcoded prices.

- User inputs stock names and quantity.
- Uses a dictionary to assign stock prices (e.g., "AAPL": 180).
- Calculates and displays total portfolio value.
- Optionally saves result to a .txt file.

📂 File: stock_tracker.py

---

### 🟢 Task 4: Basic Chatbot
A simple rule-based chatbot that responds to basic user inputs.

- Understands: "hello", "how are you", "bye".
- Responds with predefined answers.
- Console-based, uses functions, if-elif, loops, and input().

📂 File: chatbot.py
